Features

Built for speed and no friction

Everything tuned to get a working track in your hands with as few steps as possible.

Play instantly
/play, or type play <song> or p <song>. The best match downloads straight away, no list.
Search a pick-list
/search, or type search <song> or find <song>. Ten numbered results per page, tap or reply with a number.
Recently played
/recent, or just type recent or history. Last ten tracks, one tap to replay.
Inline mode
Type the bot name and a song in any chat to send a track without opening the bot.
Typo tolerance
plya, serach, fnid still work — and the bot tells you what it assumed.
Lyrics
Tap Lyrics under any track, or use /lyrics artist - title. Long lyrics arrive in several messages.
Companion mini app
An in-Telegram app for searching without typing commands.
Real filenames
Files arrive named by artist and title, never a raw hash.
Fair-use limits
A short cooldown and one download at a time per chat keep the bot fast for everyone.

Inline

Inline mode

Search from any chat Type the bot's username followed by a song name in any conversation, then pick a result. Telegram fetches the audio itself for inline results, so the file can show the source's own filename instead of the clean artist and title naming used inside the bot chat.
FAQ

Frequently asked

Do I need to use a slash command?

No. Type play, search, recent, or a number directly — the bot treats them the same as their slash versions.

What if I misspell a command?

The bot corrects common typos like "plya" or "serach" and tells you what it assumed. Real words are never rewritten.

Why do inline results show a different filename?

Telegram fetches inline audio itself, so it displays the source's own filename. Files sent inside the bot chat get proper artist and title metadata.

Is there a rate limit?

Yes — a short cooldown between downloads and one download at a time per chat keeps the service responsive for everyone.

Architecture

How it works

Telegram delivers updates to this server over a webhook. Playing a track searches the music API and downloads the top match into memory; searching sends a "Searching..." message that edits in place into a numbered, tappable list. Either way, the finished file is uploaded to Telegram with real title and artist metadata, and the track is added to your recent history.
