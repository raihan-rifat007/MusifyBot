What it does

Play instantly
/play, or type play <song> or p <song>. The best match downloads straight away, no list.
Search a pick-list
/search, or type search <song> or find <song>. Ten numbered results per page, tap or reply with a number.
Recently played
/recent, or just type recent or history. Your last ten tracks, newest first, one tap to replay.
Inline mode
Type the bot name and a song in any chat to send a track without opening the bot.
Typo tolerance
plya, serach and fnid still work, and the bot tells you what it assumed. Real words are never rewritten.
Fair-use limits
A short cooldown and one download at a time per chat keep the bot fast for everyone.
Lyrics
Tap the Lyrics button under any track, or use /lyrics artist - title. Long lyrics arrive in several messages.
Companion mini app
A brutalist in-Telegram app for searching without typing commands.
Real filenames
Files arrive named by artist and title, with the right title and performer, never a raw hash.

Inline mode

Search from any chat Type the bot's username followed by a song name in any conversation, then pick a result. Telegram fetches the audio itself for inline results, so the file can show the source's own filename instead of the clean artist and title naming used inside the bot chat.

How it works

Telegram delivers updates to this server over a webhook. Playing a track searches the music API and downloads the top match into memory; searching sends a "Searching..." message that edits in place into a numbered, tappable list. Either way, the finished file is uploaded to Telegram with real title and artist metadata, and the track is added to your recent history.
